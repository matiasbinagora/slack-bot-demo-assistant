# Writing Plans

Produce a plan that a developer can execute without guessing.

Each plan must include:

- task ID and title;
- scope and non-scope;
- affected files or boundaries;
- dependencies and predecessors;
- exact behavior and acceptance criteria;
- required skills;
- unit/integration/operational validation;
- branch and PR expectations;
- secrets, data retention, and security constraints;
- known risks and explicit OpenSpec reference or exception.

Keep tasks small, ordered, and independently verifiable. Do not write application code while planning.
