What this map explains: Slack Bolt receives the MP4 through Socket Mode; the Python app validates the 100 MB / 5 minute limits, uses FFmpeg/FFprobe for temporary evidence, sends bounded visual evidence through the Claude Agent SDK, posts an English summary with key points and supported timestamps in the original thread, and cleans up the workspace. In parallel, Orca owns scope, OpenSpec, Trello and review gates while backend-dev works in a task worktree and ships through GitHub PR/CI and controlled QA.
